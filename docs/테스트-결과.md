# 통합 테스트 결과

테스트 시나리오 26개를 프로세스 번호에 맞춰 실행한 기록입니다.

## 확인 방식

결과를 어떻게 확인했는지 구분해서 적습니다.

| 표시 | 뜻 |
|---|---|
| **사이트** | 배포 사이트에서 팀 DB에 연결해 화면을 확인 |
| **DB** | 팀 DB에서 실제 계정 권한으로 실행한 뒤 되돌림 (데이터가 남지 않음) |
| **시연** | 사이트의 시연 모드(브라우저 저장)에서 화면 흐름을 실행 |

> **시연**으로만 확인한 항목은 화면 흐름 확인입니다. 팀 DB에서는 별도의 DB 함수로 동작하므로, 발표 전에 실제 계정으로 한 번 더 실행하는 것을 권장합니다.

## 발표 전 실제 계정 점검표

- [ ] 회원 계정으로 다른 날짜 예약 → 결제 → 내 예약 표시
- [ ] 관리자 계정 예약 내역에 5초 안에 표시
- [ ] 취소 후 환불액 표시와 좌석 재오픈
- [ ] QR 체크인·체크아웃 (시작 10분 전부터)
- [ ] 알림함에 예약·빈자리·민원 답변 알림 표시
- [ ] 현장 접수: 좌석 배정 → 결제 기록 → 즉시 체크인
- [ ] 관리자 설정 저장 → 다른 기기 홈 공지 반영
- [ ] 멤버십 구매 → 다른 기기에서 표시
- [ ] 민원 접수 → 관리자 상태 변경 → 회원 화면 반영
- [ ] 업장 등록 → 사진 저장 → 관리자 승인 → 업장 찾기 공개
- [ ] 테스트 계정 탈퇴 → 재로그인 불가
