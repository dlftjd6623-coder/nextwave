# 발표 시연 순서

약 7분 분량입니다. 사이트: <https://dlftjd6623-coder.github.io/nextwave/>

## 시연 전 준비

- [ ] 브라우저 창 두 개를 띄웁니다. 왼쪽은 회원, 오른쪽은 관리자입니다. 같은 브라우저라면 한쪽은 시크릿 창으로 엽니다.
- [ ] 회원 테스트 계정과 **팀 DB 관리자 계정**으로 미리 로그인해 둡니다. 시연용 관리자(`admin@nextwave.kr`)는 팀 DB 예약이 보이지 않으니 쓰지 않습니다.
- [ ] 두 창 모두 `Ctrl + F5`로 새로고침합니다.
- [ ] 회원 계정에 진행 중인 예약이 없는지 확인합니다.
- [ ] 시연할 시간대의 좌석이 비어 있는지 확인합니다. 팀 사이트와 같은 DB를 쓰기 때문에 다른 예약이 있을 수 있습니다.
- [ ] 인터넷이 끊길 때를 대비해 `docs/images`의 캡처를 준비합니다.

## 예상 질문

| 질문 | 답변 |
|---|---|
| 두 사람이 같은 자리를 동시에 예약하면요? | DB 함수가 좌석을 잠그고 겹치는 예약을 확인해서 한 명만 성공합니다. |
| 실제 결제가 되나요? | 아닙니다. 승인 기록까지만 시연합니다. 실제 PG 연동은 다음 단계입니다. |
| 노쇼는 언제 처리되나요? | 시작 15분 뒤부터 1분 안에 처리됩니다. 30일 안에 3회면 7일간 예약이 제한됩니다. |
| 환불 기준은요? | 시작 2시간 전까지 100%, 30분 전까지 50%, 그 이후는 환불되지 않습니다. 시간권 예약도 같은 비율로 시간을 되돌립니다. |
| 탈퇴하면 데이터는요? | 이름·연락처·로그인 계정·알림·QR·멤버십 기록을 지웁니다. 예약·결제 기록은 이름 없이 남습니다. |
| 퇴실을 안 누르면요? | 종료 시각이 지나면 1분 안에 자동 퇴실되고 좌석이 다시 열립니다. |
| 왜 시연용 관리자가 따로 있나요? | 팀 DB를 건드리지 않고 화면을 체험하기 위한 계정입니다. 데이터는 그 브라우저에만 저장됩니다. |

## 시연 중 문제가 생기면

| 증상 | 대처 |
|---|---|
| "이용 규칙이 변경됐습니다" | 새로고침하고 다시 동의합니다. |
| 관리자 예약 내역이 비어 있음 | 시연용 관리자로 로그인한 것은 아닌지, 날짜가 오늘인지 확인합니다. |
| 예약이 안 됨 | 같은 시간에 진행 중인 내 예약이 있는지 확인합니다. |
| 인증 메일이 안 옴 | 스팸함을 확인합니다. 미리 만들어 둔 계정을 씁니다. |
| 사이트가 안 열림 | 준비한 캡처로 설명합니다. |
